**Geomagnetic Data Lab | Scientific Python, Data Analysis & Visualization**  
Developed an independently reproducible, synthetic-data Python portfolio inspired by my BSc Physics thesis on the May 2024 geomagnetic storm. Implemented missing-data-safe geomagnetic time-series and STFT analysis, component-based (H/X/Y/Z) geographic comparisons, latitude–longitude–time visualization, circular declination differences, interactive 3D maps and automated tests using GitHub Actions (Python 3.11/3.12).  
**GitHub:** https://github.com/ismaelberja/geomagnetic-storm-python-demo

**Caution:** Figures in this public repository use 100% fictional data; the submitted BSc research used real observatory measurements held separately.
